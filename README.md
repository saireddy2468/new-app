# SAI RESTAURANT — Premium Website

## Included
- Premium dark/gold responsive design
- Animated fixed navbar
- Mobile navigation
- Smooth scrolling
- Scroll reveal animations
- Food-card hover effects
- Menu category filtering
- Reservation form
- MySQL database schema
- Responsive gallery and testimonial sections

## Run the frontend
Open `index.html` in a browser.

The demo currently uses remote Unsplash images. An internet connection is required for those images and Google Fonts.

## Database
Import `database.sql` into MySQL:

```sql
SOURCE database.sql;
```

The frontend reservation form is currently a UI/demo form. To save reservations permanently, connect it to a backend such as PHP + MySQL or Node.js + MySQL.

- PHP: `backend/db.php`, `backend/reservation.php`
